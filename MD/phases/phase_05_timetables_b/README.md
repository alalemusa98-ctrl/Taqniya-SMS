# 📦 Phase 05-B: جدول الحصص الأسبوعي وتوزيع المعلمين والشعب (Weekly Timetable Slots)

> **المستند المرجعي المعماري والتطبيقي للمرحلة الفرعية 05-B.**

---

## 📌 1. بطاقة تعريف المرحلة (Phase Metadata)

- **اسم المرحلة البرمجي:** `phase_05_timetables_b`
- **عنوان المرحلة:** جدول الحصص الأسبوعي وتوزيع المواد والمعلمين ومنع التضارب الزمني (Weekly Timetable Slots).
- **نمط الاتصال المعماري:** `API-First` (`mode: api_first`).
- **مصدر حقيقة البيانات (DB SSoT):** [`MD/database.md`](../../database.md) (الجدول 2 في المرحلة 05 — `timetable_slots`).
- **إجمالي مسارات الـ API:** **7 مسارات برمجية**.

---

## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ومفصلة لخطوات وإجراءات تسكين الحصص بالجدول الأسبوعي وحظر تضارب الشعب والمعلمين:

1. **الخطوة 1: إدارة جدول الحصص الأسبوعي وحظر التعارضات الزمانية (`timetable_slots`):** 7 مسارات.
   - عرض قائمة وتصفية سجلات الجدول الأسبوعي (`GET /api/v1/timetable-slots`).
   - عرض مصفوفة الجدول الأسبوعي للشعبة الدراسية (`GET /api/v1/sections/:section_id/timetable`).
   - عرض جدول الحصص الأسبوعي لمعلم محدد (`GET /api/v1/teachers/:teacher_id/timetable`).
   - إضافة وتسكين حصة بالجدول الأسبوعي مع فحص التعارضات (`POST /api/v1/timetable-slots`).
   - تعديل توقيت أو مادة/معلم الحصة بالجدول (`PUT /api/v1/timetable-slots/:id`).
   - التجدول والتوزيع الجماعي لحصص الشعبة (`POST /api/v1/timetable-slots/bulk-schedule`).
   - إلغاء وتفريغ حصة من الجدول الأسبوعي (`DELETE /api/v1/timetable-slots/:id`).
