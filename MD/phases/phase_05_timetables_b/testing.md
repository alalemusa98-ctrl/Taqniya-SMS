# 🧪 مصفوفة الاختبارات والتحقق — المرحلة 05-B (Testing Specification)

> **الهدف:** توثيق مصفوفة الاختبارات الشاملة (Unit, Integration, Security, Anti-Collision Invariants) للمرحلة الفرعية 05-B لضمان جودة الأكواد ومطابقتها التامة لـ [`routes.md`](./routes.md)، [`backend.md`](./backend.md)، و [`MD/database.md`](../../database.md).

---

## 1. استراتيجية الاختبارات العامة (Testing Strategy)

- **نمط الاختبار:** اختبارات تكاملية للـ API واختبارات حظر التعارضات الزمانية (Collision Detection) للشعب والمعلمين.
- **التغطية المطلوبة:** 100% لكافة مسارات الـ API الـ 5، وقواعد التحقق، وحالات تضارب الجداول، والنزاهة المرجعية.
- **البيئة المعتمدة:** بيئة اختبار معزولة (Test Database) يتم تصفيرها وإعادة ضبطها تلقائياً قبل كل جولة اختبار.

## 2. مصفوفة الاختبارات التفصيلية (Comprehensive Test Matrix)

### 2.1 اختبارات جدول الحصص الأسبوعي (`timetable_slots`) — [الخطوة 1]

| معرف الاختبار (Test ID) | نوع الاختبار | السيناريو ووصف الحالة | المدخلات المتوقعة | النتيجة والرمز المتوقع |
| :--- | :--- | :--- | :--- | :--- |
| `TC-TBL-01` | **Integration** | استرجاع جدول الحصص بالفلترة بالصف والشعبة واليوم | `GET /api/v1/timetable-slots?class_id=5&day_of_week=sunday&page=1` | `200 OK` مع مصفوفة الحصص الهرمية لكافة الشعب و `meta`. |
| `TC-TBL-02` | **Integration** | استرجاع مصفوفة جدول الحصص الأسبوعي لشعبة محددة | `GET /api/v1/class-sections/5/timetable` | `200 OK` وهيكل الأيام والحصص للشعبة. |
| `TC-TBL-03` | **Integration** | استرجاع جدول الحصص الأسبوعي لمعلم محدد | `GET /api/v1/teachers/3/timetable` | `200 OK` وجدول نصاب حصص المعلم. |
| `TC-TBL-04` | **Unit / Validation** | **تسكين حصة بنجاح:** تسكين مادة لمعلم بشعبة في وقت ويوم شاغر | `year: 1, section: 5, day: 'sunday', period: 1, assignment: 10` | `201 Created` وحفظ السجل وإرجاع تفاصيل الصف والشعبة والمادة والمعلم. |
| `TC-TBL-05` | **Conflict / Invariant** | **قيد تفرد حصة الشعبة (uq_timetable_section_slot):** منع تسكين حصتين لنفس الشعبة في نفس اليوم والحصة | محاولة تسكين حصة لشعبة في توقيت مشغول مسبقاً | `409 Conflict` (`uq_timetable_section_slot`). |
| `TC-TBL-06` | **Collision / Conflict** | **قيد حظر تضارب المعلم:** منع تسكين المعلم لتدريس شعبتين مختلفتين في نفس اليوم والحصة | محاولة تسكين المعلم لشعبة أخرى في نفس الوقت | `409 Conflict` (تضارب في جدول المعلم). |
| `TC-TBL-07` | **Validation** | رفض مدخلات بيوم غير صالح أو فترة غير موجودة | `day_of_week: 'funday', period_slot_id: 9999` | `422 Unprocessable Entity`. |
| `TC-TBL-08` | **Integration** | **تعديل وتحديث الحصة بالجدول:** نقل توقيت الحصة إلى حصة أخرى شاغرة | `PUT /api/v1/timetable-slots/1` مع `period_slot_id: 2` | `200 OK` وتحديث السجل. |
| `TC-TBL-09` | **Conflict** | منع تعديل ونقل الحصة إلى وقت يتعارض مع حصة أخرى للشعبة أو المعلم | `PUT` إلى وقت مشغول | `409 Conflict`. |
| `TC-TBL-10` | **Soft Delete** | حذف وإلغاء حصة من الجدول الأسبوعي | `DELETE /api/v1/timetable-slots/1` | `200 OK` وضبط `deleted_at` وتفريغ التوقيت. |
