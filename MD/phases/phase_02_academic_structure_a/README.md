## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ودقيقة للكيانات الجذرية الموزعة على الخطوات التنفيذية الثلاث:

1. **الخطوة 1: إدارة السنوات الدراسية (`academic_years`):** [5 مسارات]
   - جلب وبحث قائمة السنوات الدراسية، إنشاء سنة جديدة، تعديل بيانات سنة، حذف سنة غير مرتبطة (Soft Delete)، وتفعيل السنة النشطة حالياً (`is_active = 1`) بمعاملة ذرية متكاملة.
2. **الخطوة 2: كتالوج الفترات المرجعي (`academic_terms` - Master Catalog):** [4 مسارات]
   - عرض كتالوج الفترات المعياري، إضافة فترة للكتالوج، تعديل بيانات فترة، وحذف فترة غير مستخدمة.
3. **الخطوة 3: إدارة المراحل التعليمية (`academic_stages`):** [4 مسارات]
   - جلب وبحث قائمة المراحل التعليمية مرتبة بحسب `order_index`، إضافة مرحلة، تعديل مرحلة، وحذف مرحلة تعليمية فارغة.

### 🔴 ما يقع خارج نطاق المرحلة (Out of Scope):
- إدارة الفصول والصفوف الدراسية (`classes`) وتخصيص فترات الصفوف (`class_academic_terms`) والشعب (`sections`) $\rightarrow$ نطاق المرحلة `02-B`.
- إدارة المواد التعليمية (`subjects`) وربطها بالصفوف (`class_subjects`) $\rightarrow$ نطاق المرحلة `02-C`.
