## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ومفصلة لخطوة توزيع الكادر التعليمي على المواد والشعب بالعام الدراسي:

1. **الخطوة 1: إدارة سجل وجدول إسناد التدريس الأكاديمي (`teaching_assignments`):** [5 مسارات]
   - **استعراض وتصفية توزيع الكادر التعليمي على المواد والشعب بالصفوف:** `GET /api/v1/teaching-assignments`.
   - **استعراض النصاب التدريسي والمواد لمعلم محدد بالعام الدراسي:** `GET /api/v1/teachers/:teacher_id/assignments`.
   - **إسناد وتكليف معلم بمادة لشعبة:** `POST /api/v1/teaching-assignments`.
   - **تعديل إسناد التدريس أو تغيير المعلم/المادة:** `PUT /api/v1/teaching-assignments/:id`.
   - **فك وإلغاء إسناد تدريس مادة مع فحص الحماية المرجعية (RESTRICT):** `DELETE /api/v1/teaching-assignments/:id`.

### 🔴 ما يقع خارج نطاق المرحلة (Out of Scope):
- إدارة ملفات المعلمين وحساباتهم $\rightarrow$ تابعة للمرحلة `03-A` (`teachers`).
- تسكين جداول الحصص الأسبوعية $\rightarrow$ تابعة للمرحلة `05` (`timetable_slots`).
- إنشاء الواجبات والاختبارات والامتحانات $\rightarrow$ محالة إلى المراحل `06` (الواجبات)، `07` (الاختبارات القصيرة)، و `08` (الامتحانات).
