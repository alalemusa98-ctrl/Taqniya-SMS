## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ومفصلة لخطوة إسناد التدريس والنصاب الأكاديمي بالمدرسة:

1. **الخطوة 1: إدارة سجل وجدول إسناد التدريس الأكاديمي (`teaching_assignments`):** 6 مسارات.
   - **عرض وتصفية جدول إسناد التدريس بالعام الدراسي المعين والترقيم المالي:** `GET /api/v1/teaching-assignments`.
   - **عرض النصاب التدريسي والمواد والصفوف لمعلم محدد بالعام:** `GET /api/v1/teachers/:teacher_id/assignments`.
   - **عرض وبحث معلمي ومناهج الصف الدراسي والمعاينة بحسب الشعبة:** `GET /api/v1/classes/:class_id/assignments`.
   - **إنشاء وتعيين إسناد تدريس ثلاثي مركّب (الشعبة + المادة + المعلم):** `POST /api/v1/teaching-assignments`.
   - **تحديث وتعديل المعلم المكلف بتدريس المادة والشعبة بالعام:** `PUT /api/v1/teaching-assignments/:id`.
   - **فك وإزالة إسناد التدريس غير المرتبط بدرجات:** `DELETE /api/v1/teaching-assignments/:id`.
