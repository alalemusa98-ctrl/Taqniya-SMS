## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ومفصلة للخطوات الثلاث المستقلة بالمرحلة الفرعية 02-B:

1. **الخطوة 1: إدارة الصفوف وتحديد تبعيتها للمراحل (`classes`):** [4 مسارات]
   - جلب وبحث وتصفية الصفوف الدراسية بالمرحلة والمستوى الرقمي، إنشاء صف جديد وتسكينه بمرحلة (`stage_id`, `name`, `grade_level`)، تعديل بيانات صف، والحذف المنطقي لصف غير مرتبط.
2. **الخطوة 2: إدارة بنك الشُعب العامة (`sections` - Master Sections):** [4 مسارات]
   - عرض وبحث كتالوج الشعب العامة بالمدرسة، إنشاء مسمى شعبة عامة (`name`)، تعديل مسمى شعبة، وحذف شعبة عامة غير مستخدمة.
3. **الخطوة 3: إدارة بنك المواد الدراسية العامة (`subjects` - Master Catalog):** [4 مسارات]
   - عرض وبحث بنك المواد العامة بالمدرسة، إضافة مادة تعليمية جديدة (`name`, `code`)، تعديل مادة، وحذف مادة عامة غير مسندة لمقررات صفوف.

### 🔴 ما يقع خارج نطاق المرحلة (Out of Scope):
- إدارة السنوات الدراسية (`academic_years`) وكتالوج الفترات (`academic_terms`) والمراحل (`academic_stages`) $\rightarrow$ تابعة للمرحلة `02-A`.
- تخصيص فترات وتواريخ الصفوف (`class_academic_terms`)، وربط الصفوف بالشعب (`class_sections`)، وتسكين مقررات المواد والدرجات بالفصول (`class_subjects`) $\rightarrow$ تابعة للمرحلة `02-C`.
