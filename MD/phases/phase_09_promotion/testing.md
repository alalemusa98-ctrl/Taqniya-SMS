# 🧪 مصفوفة الاختبارات والتحقق — المرحلة 09 (Testing Specification)

> **الهدف:** توثيق مصفوفة الاختبارات الشاملة (Unit, Integration, Security, Invariant Integrity) للمرحلة 09 لضمان جودة الأكواد ومطابقتها التامة لـ [`routes.md`](./routes.md)، [`backend.md`](./backend.md)، و [`MD/database.md`](../../database.md).

---

## 1. استراتيجية الاختبارات العامة (Testing Strategy)

- **نمط الاختبار:** اختبارات تكاملية للـ API، اختبارات النزاهة التجميدية لكائنات الـ JSON (`transcript_data`)، اختبارات المعاملات الذرية للترحيل الجماعي، واختبارات حوكمة الصلاحيات (RBAC).
- **التغطية المطلوبة:** 100% لكافة مسارات الـ API الـ 8، وقواعد التحقق، وحالات التعارض (409 Conflict)، واختبارات تنبيه السعة المنخفضة للشعب.
- **البيئة المعتمدة:** بيئة اختبار معزولة (Test Database) يتم تصفيرها وإعادة ضبطها تلقائياً قبل كل جولة اختبار.

### 2.1 اختبارات أرشفة الصحائف المدرسية (`student_transcripts`) — [الخطوة 1]

| :--- | :--- | :--- | :--- | :--- |
| `TC-TRN-01` | **Integration** | استرجاع شبكة بطاقات الصفوف وكشف ترتيب الطلاب مع الفلترة بـ grade_level والترقيم | `GET /api/v1/transcripts?academic_year_name=2024/2025&grade_level=5&sort_by=percentage&sort_order=desc&page=1` | `200 OK` مع بطاقات `classes_summary` وكشف `transcripts` المرتب تنازلياً من الأعلى تقييماً للأقل و `meta`. |
| `TC-TRN-02` | **Integration** | البحث النصي باسم الطالب أو رمزه المؤسسي | `GET /api/v1/transcripts?search=STU-3001` | `200 OK` ومطابقة صحائف الطالب المحدد. |
| `TC-TRN-03` | **Integration** | استرجاع لقطة الصحيفة التجميدية الكاملة بالـ JSON | `GET /api/v1/transcripts/1` | `200 OK` وتفاصيل المواد والدرجات وأعمال السنة والامتحان والدور الثاني. |
| `TC-TRN-04` | **Integration** | استرجاع السجل التاريخي الكامل لصحائف طالب محدد | `GET /api/v1/students/101/transcripts` | `200 OK` وكافة الصحائف الفصلية والسنوية السابقة. |
| `TC-TRN-05` | **Unit / Validation** | **تجميد وإصدار صحيفة دراسية بنجاح:** حفظ لقطة الدرجات وكائن الـ JSON | بيانات الطالب، الدرجات، وكائن `transcript_data` | `201 Created` وحفظ السجل بجدول `student_transcripts`. |
| `TC-TRN-06` | **Conflict / Invariant** | **قيد تفرد الصحيفة (uq_student_transcript_term):** منع تكرار إصدار صحيفة لنفس الفترة للطالب | محاولة تجميد صحيفة لنفس الطالب والعام والسمستر مجدداً | `409 Conflict` (`uq_student_transcript_term`). |
| `TC-TRN-07` | **Validation** | رفض تجميد صحيفة بدون درجات مواد أو بمجموع غير صالح | `transcript_data: []` أو `total_score: -10` | `422 Unprocessable Entity`. |
