- **مصدر حقيقة البيانات الأساسي (DB SSoT):** [`MD/database.md`](../../database.md) (الجداول الـ 3: `users`, `personal_access_tokens`, `audit_logs`).

- **الأدوار المعنية:** كافة مستخدمي المنظومة (Admin, Teacher, Student, Parent) للمصادقة؛ مدير النظام (Admin) حصراً لإدارة الحسابات والتدقيق.

## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ومفصلة لخطوات وإجراءات الهوية والمصادقة وإدارة المستخدمين والتدقيق:

1. **المجموعة 1: المصادقة وإدارة الجلسات (`auth`):** [4 مسارات]
   - **تسجيل الدخول الموحد بالرمز المؤسسي:** `POST /api/v1/auth/login`.
   - **استرجاع الملف الشخصي والجلسة النشطة:** `GET /api/v1/auth/me`.
   - **تسجيل الخروج وإبطال التوكن:** `POST /api/v1/auth/logout`.
   - **تغيير كلمة المرور الذاتي للمستخدم:** `POST /api/v1/auth/change-password`.

2. **المجموعة 2: إدارة حسابات المستخدمين (`users`):** [4 مسارات]
   - **استعراض وتصفية وبحث حسابات المستخدمين:** `GET /api/v1/users`.
   - **عرض تفاصيل حساب مستخدم محدد:** `GET /api/v1/users/:id`.
   - **تفعيل أو إيقاف حساب المستخدم:** `PUT /api/v1/users/:id/status`.
   - **إعادة تعيين كلمة المرور من قِبل الإدارة:** `POST /api/v1/users/:id/reset-password`.

3. **المجموعة 3: سجلات التدقيق الأمني والحركات (`audit_logs`):** [مساران]
   - **استعراض وتصفية سجلات التدقيق الأمني بالترقيم:** `GET /api/v1/audit-logs`.
   - **عرض تفاصيل حركة تدقيق محددة ومقارنة القيم:** `GET /api/v1/audit-logs/:id`.

### 🔴 ما يقع خارج نطاق المرحلة (Out of Scope):
- إنشاء الملفات الأكاديمية والبيانات الشخصية للمعلمين $\rightarrow$ تابعة للمرحلة `03` (`teachers`).
- إنشاء ملفات الطلاب وأولياء الأمور وتسجيلهم بالشعب $\rightarrow$ تابعة للمرحلة `04` (`students`, `guardians`).
