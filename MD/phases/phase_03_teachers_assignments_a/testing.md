# 🧪 مصفوفة الاختبارات والتحقق — المرحلة 03-A (Testing Specification)

> **الهدف:** توثيق مصفوفة الاختبارات الشاملة (Unit, Integration, Security, Business Invariants) للمرحلة الفرعية 03-A لضمان جودة الأكواد ومطابقتها التامة لـ [`routes.md`](./routes.md)، [`backend.md`](./backend.md)، و [`MD/database.md`](../../database.md).

---

## 1. استراتيجية الاختبارات العامة (Testing Strategy)

- **نمط الاختبار:** اختبارات تكاملية للـ API واختبارات منطق الأعمال للخدمات والمعاملات الذرية والقيود المرجعية.
- **التغطية المطلوبة:** 100% لكافة مسارات الـ API الـ 5، وقواعد التحقق، وحالات الحدود (Boundary Cases)، والنزاهة المرجعية.
- **البيئة المعتمدة:** بيئة اختبار معزولة (Test Database) يتم تصفيرها وإعادة ضبطها تلقائياً قبل كل جولة اختبار.

## 2. مصفوفة الاختبارات التفصيلية (Comprehensive Test Matrix)

### 2.1 اختبارات إدارة ملفات المعلمين (`teachers`) — [الخطوة 1]

| معرف الاختبار (Test ID) | نوع الاختبار | السيناريو ووصف الحالة | المدخلات المتوقعة | النتيجة والرمز المتوقع |
| :--- | :--- | :--- | :--- | :--- |
| `TC-TCH-01` | **Integration** | استرجاع قائمة المعلمين مع الترقيم والفلترة بالتخصص | `GET /api/v1/teachers?specialization=الرياضيات` | `200 OK` مع مصفوفة المعلمين و `meta`. |
| `TC-TCH-02` | **Integration** | البحث النصي بالاسم أو الرمز المؤسسي | `GET /api/v1/teachers?search=TCH-2001` | `200 OK` ومطابقة السجل المطلوب. |
| `TC-TCH-03` | **Integration** | استرجاع تفاصيل ملف معلم محدد | `GET /api/v1/teachers/1` | `200 OK` وتفاصيل الحساب والبيانات المهنية. |
| `TC-TCH-04` | **Negative** | محاولة جلب ملف معلم غير موجود | `GET /api/v1/teachers/99999` | `404 Not Found`. |
| `TC-TCH-05` | **Atomic / Unit** | **إنشاء معلم وتوليد الحساب الموحد (Atomic):** إنشاء معلم جديد والتحقق من إنشاء حساب `users` برمز `TCH-XXXX` | `full_name: 'علي الورفلي', phone: '0934567890', password: 'Password123!'` | `201 Created`، وحفظ السجلين في `teachers` و `users`. |
| `TC-TCH-06` | **Conflict** | منع تكرار رقم هاتف المعلم المسجل مسبقاً | `phone: '0912345678'` (مستخدم مسبقاً) | `409 Conflict`. |
| `TC-TCH-07` | **Validation** | رفض مدخلات بدون الاسم الرباعي أو بكلمة مرور ضعيفة | `full_name: '', password: '123'` | `422 Unprocessable Entity`. |
| `TC-TCH-08` | **Integration** | تعديل البيانات المهنية والشخصية للمعلم | `PUT /api/v1/teachers/1` مع بيانات صالحة | `200 OK` وتحديث السجل. |
| `TC-TCH-09` | **Conflict** | منع تعديل رقم الهاتف إلى رقم مستخدم لمعلم آخر | `PUT` برقم هاتف معلم آخر | `409 Conflict`. |
| `TC-TCH-10` | **Relational Integrity** | **منع حذف معلم مرتبط بإسناد تدريس (RESTRICT):** محاولة حذف معلم مسجل بـ `teaching_assignments` | `DELETE /api/v1/teachers/1` لمعلم له إسنادات | `409 Conflict` ورفض الحذف. |
| `TC-TCH-11` | **Soft Delete** | حذف معلم حر غير مرتبط بإسنادات تدريس | `DELETE /api/v1/teachers/3` لمعلم بدون إسناد | `200 OK` وضبط `deleted_at` للمعلم وحسابه. |
