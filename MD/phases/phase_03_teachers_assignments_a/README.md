## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ومفصلة لخطوة إدارة الكادر التعليمي بالمدرسة:

1. **الخطوة 1: إدارة سجل وملفات المعلمين (`teachers`):** [5 مسارات]
   - **استعراض وبحث قائمة المعلمين بالتخصص وحالة الحساب والترقيم:** `GET /api/v1/teachers`.
   - **استعراض تفاصيل ملف معلم محدد وبيانات حسابه الموحد:** `GET /api/v1/teachers/:id`.
   - **إنشاء ملف معلم جديد وتوليد حساب الدخول الموحد (`TCH-XXXX`) ذرياً:** `POST /api/v1/teachers`.
   - **تعديل البيانات الشخصية والمهنية للمعلم:** `PUT /api/v1/teachers/:id`.
   - **حذف ملف المعلم وحسابه بشرط عدم وجود إسناد تدريس (RESTRICT):** `DELETE /api/v1/teachers/:id`.

### 🔴 ما يقع خارج نطاق المرحلة (Out of Scope):
- إسناد المعلمين للمواد والشعب الدراسية بالفصول $\rightarrow$ تابعة للمرحلة `03-B` (`teaching_assignments`).
- تسكين جداول الحصص الأسبوعية للمعلمين $\rightarrow$ تابعة للمرحلة `05`.
- صلاحيات رصد الواجبات والامتحانات $\rightarrow$ تابعة للمراحل `06` و `07` و `08`.
