## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ومفصلة لخطوة إدارة الكادر التعليمي بالمدرسة:

1. **الخطوة 1: إدارة سجل وملفات المعلمين (`teachers`):** 5 مسارات.
   - **عرض قائمة المعلمين والجلب بحسب التخصص والترقيم المالي:** `GET /api/v1/teachers`.
   - **عرض ملف معلم محدد بتفاصيله وحساب دخوله:** `GET /api/v1/teachers/:id`.
   - **إضافة وتمرير سجل معلم جديد وربطه بالحساب الموحد (`TCH-XXXX`):** `POST /api/v1/teachers`.
   - **تعديل البيانات الشخصية والمهنية للمعلم:** `PUT /api/v1/teachers/:id`.
   - **حذف ملف معلم غير مرتبط بإسنادات تدريس:** `DELETE /api/v1/teachers/:id`.
