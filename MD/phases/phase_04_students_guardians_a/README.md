## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ومفصلة لخطوات إدارة سجلات الطلاب وأولياء الأمور بالمنظومة:

1. **الخطوة 1: إدارة سجل وملفات الطلاب (`students`):** 5 مسارات.
   - عرض قائمة وبحث الطلاب (`GET /api/v1/students`).
   - عرض ملف طالب محدد وحسابه الموحد (`GET /api/v1/students/:id`).
   - إنشاء ملف طالب جديد وتوليد حساب الدخول الموحد `STU-XXXX` (`POST /api/v1/students`).
   - تعديل البيانات الشخصية للطالب (`PUT /api/v1/students/:id`).
   - حذف ملف طالب غير مسجل أفقياً (`DELETE /api/v1/students/:id`).

2. **الخطوة 2: إدارة سجل وملفات أولياء الأمور (`guardians`):** 5 مسارات.
   - عرض قائمة وبحث أولياء الأمور (`GET /api/v1/guardians`).
   - عرض تفاصيل ملف ولي أمر محدد وقائمة أبنائه (`GET /api/v1/guardians/:id`).
   - إنشاء ملف ولي أمر جديد وتوليد حساب الدخول الموحد `PAR-XXXX` (`POST /api/v1/guardians`).
   - تعديل بيانات ولي الأمر ورقم التواصل (`PUT /api/v1/guardians/:id`).
   - حذف ملف ولي أمر غير مرتبط بأبناء (`DELETE /api/v1/guardians/:id`).

3. **الخطوة 3: إدارة روابط الوصاية والارتباط الأسري (`guardian_students`):** 4 مسارات.
   - عرض قائمة أبناء ولي أمر محدد (`GET /api/v1/guardians/:guardian_id/students`).
   - ربط ولي أمر بطالب وتعيين الصفة الرئيسية `is_primary` (`POST /api/v1/guardian-students`).
   - تعديل صفة الوصاية (`PUT /api/v1/guardian-students/:id`).
   - إلغاء فك ربط الوصاية بين ولي الأمر والطالب (`DELETE /api/v1/guardian-students/:id`).
