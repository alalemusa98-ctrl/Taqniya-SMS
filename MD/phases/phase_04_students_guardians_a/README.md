## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ومفصلة لخطوات إدارة ملفات الطلاب وأولياء الأمور وروابط الوصاية الأسرية:

1. **الخطوة 1: إدارة ملفات وسجل الطلاب (`students`):** [4 مسارات]
   - **استعراض وبحث قائمة الطلاب:** `GET /api/v1/students`.
   - **استعراض تفاصيل ملف طالب محدد:** `GET /api/v1/students/:id`.
   - **إنشاء وتعديل ملف طالب وتوليد حسابه الذري (`STU-XXXX`):** `POST` & `PUT /api/v1/students`.
   - **حذف ملف طالب مع فحص الحماية المرجعية (RESTRICT):** `DELETE /api/v1/students/:id`.

2. **الخطوة 2: إدارة ملفات أولياء الأمور (`guardians`):** [4 مسارات]
   - **استعراض وبحث قائمة أولياء الأمور:** `GET /api/v1/guardians`.
   - **استعراض تفاصيل ملف ولي أمر محدد:** `GET /api/v1/guardians/:id`.
   - **إنشاء وتعديل ملف ولي أمر وتوليد حسابه الذري (`PAR-XXXX`):** `POST` & `PUT /api/v1/guardians`.
   - **حذف ملف ولي أمر مع فحص الحماية المرجعية (RESTRICT):** `DELETE /api/v1/guardians/:id`.

3. **الخطوة 3: إدارة روابط الوصاية الأسرية (`guardian_students`):** [4 مسارات]
   - **استعراض سجلات الوصاية بالمنظومة:** `GET /api/v1/guardian-students`.
   - **استعراض قائمة الأبناء المكفولين لولي أمر محدد:** `GET /api/v1/guardians/:guardian_id/students`.
   - **ربط وتعديل وصاية ولي أمر بطالب (Combined POST & PUT):** `POST` & `PUT /api/v1/guardian-students`.
   - **فك وإلغاء رابط الوصاية:** `DELETE /api/v1/guardian-students/:id`.

### 🔴 ما يقع خارج نطاق المرحلة (Out of Scope):
- تسكين الطلاب وتوزيعهم على الفصول والشعب وأرقام الجلوس $\rightarrow$ تابعة للمرحلة `04-B` (`student_enrollments`).
- رصد الدرجات والامتحانات والواجبات $\rightarrow$ محالة إلى المراحل `06` و `07` و `08`.
