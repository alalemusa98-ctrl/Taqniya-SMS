# 🖥️ مواصفات Frontend — المرحلة 04-A (User Interface & UX)

> **الهدف:** توثيق تفاصيل واجهات المستخدم، وتدفق التفاعل (User Interaction Flows)، واللوحات الجانبية المنبثقة (Slide-over Drawers)، وجداول الطلاب وأولياء الأمور وشبكة الوصاية الأسرية، ونوافذ التأكيد (Confirmation Modals)، ومعالجة كافة حالات الشاشات الأربع وسلوك مسارات الـ API في المرحلة الفرعية 04-A المطابقة بنسبة 100% لـ [`MD/routes.md`](./routes.md) و [`MD/design_rules.md`](../../design_rules.md).  
> 
> ⚠️ **تكامل حوكمي صريح وملزم — مرجع الاستجابات (Network SSoT):**  
> ملف [`routes.md`](./routes.md) هو **المصدر الرئيسي والحصري والوحيد لكافة استجابات ومدخلات الـ API (Network SSoT)**. يلتزم مطور الواجهة برسم وتحديد معالجات الاستجابة (Response Handlers)، قراءة حقول البيانات (`data`, `meta`)، واستخراج نصوص التنبيهات والأخطاء (`message`, `errors`) بناءً على الهياكل والرموز المسجلة في ملف [`routes.md`](./routes.md) حصراً دون أي افتراض شخصي.

---

## 🎨 المعايير العامة لنظام التصميم والواجهة (Spatial UI & RTL Standards)

- **اتجاه العرض:** دعم كامل للغة العربية والاتجاه من اليمين لليسار (`dir="rtl"`).
- **النمط البصري (Spatial UI):** كروت طلاب وأولياء أمور عائمة، شارات رقمية مميزة للأكواد الموحدة (`STU-XXXX`, `PAR-XXXX`)، وخلفيات زجاجية خفيفة (Backdrop Blur).
- **الحالات التفاعلية الأربع (The 4 UI States):**
  1. **Loading State:** عروض رمادية متأرجحة (Skeleton Rows & Cards) للحفاظ على أبعاد الصفحة أثناء جلب البيانات.
  2. **Empty State:** بطاقة فارغة توضح عدم وجود سجلات مع زر إضافة مباشر.
  3. **Error State:** شريط تنبيه أحمر عائم في أعلى الصفحة مع زر إعادة المحاولة (Retry Button) بالإضافة إلى رسائل Toast المنبثقة.
  4. **Success State:** عرض الجداول والكروت المكتملة مع الشارات والأزرار التفاعلية (👁️ معاينة، ✏️ تعديل، 🗑️ حذف).

## 🎓 1. شاشات وإجراءات إدارة الطلاب (`students`) — (الخطوة 1)

### 1.1 مصفوفة الإجراءات والروابط بالواجهة:
| الإجراء بالواجهة (UI Action) | نقطة الاتصال في `routes.md` | المكون التفاعلي بالواجهة (UI Component) | رمز النجاح | مرجع العقد في `routes.md` |
| :--- | :--- | :--- | :-: | :--- |
| **استعراض وبحث قائمة الطلاب** | `GET /api/v1/students` | جدول كشف الطلاب (`Students Data Table`) | `200 OK` | [في routes.md](./routes.md) |
| **معاينة ملف طالب محدد** | `GET /api/v1/students/:id` | لوحة تفاصيل ملف الطالب (`Student Profile Drawer`) | `200 OK` | [في routes.md](./routes.md) |
| **إنشاء وتعديل ملف طالب** | `POST` & `PUT /api/v1/students` | اللوحة الجانبية المنبثقة (`Slide-over Drawer`) | `201 Created` / `200 OK` | [في routes.md](./routes.md) |
| **حذف ملف طالب** | `DELETE /api/v1/students/:id` | نافذة التأكيد المركزية (`Confirmation Modal`) | `200 OK` | [في routes.md](./routes.md) |

---

### 1.2 تفاصيل التصميم وتدفق التفاعل:

#### 🔹 [UI-1.1] `GET /api/v1/students` — استعراض وبحث قائمة الطلاب:
* **عناصر الصفحة الرئيسية:**
  - **شريط الفلترة والبحث العلوي:** حقل بحث نصي سريع (الاسم أو `STU-XXXX`)، قائمة فلترة الجنس (`ذكر`، `أنثى`)، وزر أزرق رئيسي: `+ إضافة طالب جديد`.
  - **جدول الطلاب (Students Table):** يستعرض الأعمدة المستخرجة حصراً من كائن `data` في `routes.md`:
    1. `#` (`id`).
    2. `كود الطالب` (شارة رمادية مميزة `user_code`).
    3. `اسم الطالب الرباعي` (`full_name`).
    4. `الصف والشعبة الحالية` (`class_section`).
    5. `تاريخ الميلاد` (`birth_date`).
    6. `الجنس` (`gender`).
    7. `رقم الهاتف` (`phone`).
    8. `الإجراءات` (معاينة 👁️، تعديل ✏️، حذف 🗑️).
  - **شريط الترقيم (Pagination Bar):** أسفل الجدول يستعرض أزرار الصفحات وأرقام `meta.current_page` و `meta.total`.
* **معالجة الاستجابات (Response Handlers — طبق `routes.md`):**
  - **Success (`200 OK`):** رسم الجدول وضبط أزرار الترقيم.
  - **Empty (`data: []`):** عرض بطاقة الحالة الفارغة مع زر `+ إضافة أول طالب`.
  - **Error (`401` / `403` / `500`):** إظهار Toast أحمر بنص `message` القادم من `routes.md`.

#### 🔹 [UI-1.3] `POST` & `PUT /api/v1/students` — إنشاء وتعديل ملف طالب:
* **المكون:** لوحة جانبية منبثقة من اليمين (Slide-over Drawer) بعرض `500px` مع تأثير تعتيم خلفي تحتوي على الحقول:
  - `الاسم الرباعي واللقب` (`full_name`).
  - `الجنس` (محدد راديو `gender`).
  - `تاريخ الميلاد` (`birth_date`).
  - `رقم هاتف التواصل` (`phone`).
  - `كلمة المرور` (`password` - إجباري بالإنشاء، اختياري بالتعديل).
  - **قسم التسكين الأكاديمي المباشر (اختياري - Optional Enrollment):**
    - `الصف والشعبة الدراسية` (قائمة اختيار منسدلة `class_section_id` لتسكين الطالب فوراً).
    - `رقم الجلوس` (حقل نصي اختياري `seating_number`).
* **معالجة الاستجابات (Response Handlers — طبق `routes.md`):**
  - **نجاح الإنشاء أو التعديل (`201 Created` / `200 OK`):** إغلاق اللوحة، إظهار Toast أخضر بنص `message` في `routes.md` ("تم إنشاء ملف الطالب وتسكينه بالشعبة بنجاح")، وتحديث جدول الطلاب.
  - **أخطاء التحقق (`422 Unprocessable Entity`):** رسم رسائل الخطأ أسفل الحقول المعنية.

#### 🔹 [UI-1.4] `DELETE /api/v1/students/:id` — حذف ملف طالب:
* **المكون:** نافذة تأكيد مركزية (Confirmation Modal).
* **معالجة الاستجابات:** عند وجود درجات أو تسكين سابق يرجع الخادم `409 Conflict` ويُعرض Toast تحذيري بالنص الصريح في `routes.md`.
