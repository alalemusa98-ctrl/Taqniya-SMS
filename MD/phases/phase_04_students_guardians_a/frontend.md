### 1.2 التفاصيل والتصميم والتفاعل مع المسارات (Detailed UI & Route Action Flow):

#### 🔹 [المسار 1.1] `GET /api/v1/students` — عرض وتصفية قائمة الطلاب:
* **شكل المكون بالواجهة (Listing Component):**
  - **جدول بيانات الطلاب (Students Data Table):** يستعرض الأعمدة:
    1. `#` (`id`).
    2. `الرمز الموحد` (شارة `user_code` مثل: `STU-3001`).
    3. `اسم الطالب الرباعي` (`full_name`).
    4. `الصف والشعبة` (شارة زرقاء تجمع `class_section` مثل: `الصف الخامس - شعبة أ` أو رمادي `غير مسكن`).
    5. `الجنس` (شارة `male` ذكر / `female` أنثى).
    6. `تاريخ الميلاد` (`birth_date`).
    7. `رقم الهاتف` (`phone`).
    8. `الإجراءات` (معاينة 👁️، أيقونة التعديل ✏️، وأيقونة الحذف 🗑️).
  - **شريط الفلترة والبحث العلوي (Filter Header):**
    - شريط بحث نصي باسم الطالب أو رمزه الموحد.
    - قائمة منسدلة `Select Dropdown` لفلترة الطلاب بحسب الجنس.
    - زر رئيسي جانبي باللون الأزرق: `+ إضافة طالب جديد`.
  - **شريط الترقيم المالي (Pagination Bar):** أسفل الجدول يستعرض `meta.total`, `meta.page`, و `meta.per_page`.
* **حالات المعالجة المرئية (UI States):**
  - **Loading State:** عرض هيكل رمادي متأرجح (Skeleton Table Loader).
  - **Empty State:** رسالة توضيحية "لا يوجد طلاب مسجلون بحسب معايير البحث والفلترة المختارة".

#### 🔹 [المسار 1.2] `GET /api/v1/students/:id` — عرض ملف طالب محدد:
* **شكل المكون وتدفق التفاعل:** عند الضغط على 👁️ المعاينة يتم فتح اللوحة الجانبية المنبثقة (**Slide-over Drawer**) بعرض `500px` لعرض كارت معتم تفصيلي يستعرض كافة بيانات الطالب وحساب دخوله الموحد مع شارة `class_section`.

#### 🔹 [المسار 1.3] `POST /api/v1/students` — إنشاء ملف طالب جديد:
* **شكل المكون وتدفق التفاعل (Create Flow & Interaction):**
  - عند الضغط على زر `+ إضافة طالب جديد` يتم فتح **لوحة جانبية منبثقة (Slide-over Drawer)** بعرض `500px` مع غطاء خلفي معتم (Backdrop Dim).
  - **حقول النموذج بالدرور (Form Controls):**
    1. `الاسم الرباعي واللقب` (حقل نصي `full_name` مطلوب).
    2. `الجنس` (اختيار `male` ذكر / `female` أنثى).
    3. `تاريخ الميلاد` (`Date Picker` لـ `birth_date`).
    4. `رقم الهاتف` (حقل نصي `phone`).
    5. `كلمة المرور للحساب الموحد` (حقل كلمة سر آمن `password`).
  - **أزرار التحكم:** زر `حفظ الطالب وتوليد الحساب` (باللون الأزرق) وزر `إلغاء`.
* **سلوك المعالجة والتنبيهات (Response Handlers):**
  - **نجاح الإضافة (`201 Created`):** إغلاق الدرور تلقائياً، إظهار تنبيه نجاح أخضر "تم إنشاء ملف الطالب وتوليد حساب الدخول الموحد بنجاح"، وتحديث جدول الطلاب.
  - **أخطاء التحقق (`422 Unprocessable`):** عرض رسائل الخطأ باللون الأحمر تحت الحقول.

#### 🔹 [المسار 1.4] `PUT /api/v1/students/:id` — تعديل بيانات طالب:
* عند الضغط على أيقونة التعديل ✏️، فتح **نفس اللوحة الجانبية المنبثقة (Slide-over Drawer)** محملة ببيانات الطالب.
* **نجاح التعديل (`200 OK`):** إغلاق الدرور وإظهار Toast أخضر "تم تحديث بيانات ملف الطالب بنجاح".

#### 🔹 [المسار 1.5] `DELETE /api/v1/students/:id` — حذف ملف طالب:
* الضغط على أيقونة الحذف 🗑️ يفتح **نافذة تأكيد مركزية (Confirmation Modal Alert)**.
* **حظر الحذف المرجعي (`403 Forbidden`):** إظهار تنبيه تحذيري: "لا يمكن حذف ملف الطالب لارتباطه بتسكين أفقياً أو درجات مرصودة (RESTRICT)".

### 2.2 التفاصيل والتصميم والتفاعل مع المسارات (Detailed UI & Route Action Flow):

#### 🔹 [المسار 2.1] `GET /api/v1/guardians` — عرض وتصفية أولياء الأمور:
* **جدول بيانات أولياء الأمور (Guardians Data Table):** يستعرض الأعمدة (`#`, `الرمز الموحد PAR-XXXX`, `اسم ولي الأمر`, `رقم الهاتف`, `صلة القرابة`, `عدد الأبناء المرتبطين`, و`الإجراءات` 👁️, ✏️, 🗑️).
* **زر الإضافة العلوي:** `+ إضافة ولي أمر جديد`.

#### 🔹 [المسار 2.2] `GET /api/v1/guardians/:id` — عرض ملف ولي أمر والأبناء:
* **تدفق التفاعل:** عند الضغط على 👁️ المعاينة يتم فتح اللوحة الجانبية المنبثقة (**Slide-over Drawer**) بعرض `500px` يستعرض كافة بيانات ولي الأمر وقائمة الأبناء المرتبطين به مع بيان الصف والشعبة `class_section` لكل ابن (مثل `محمد علي الفيتوري - الصف الخامس - شعبة أ` و `فاطمة علي الفيتوري - الصف الرابع - شعبة ب`) مع زر سريع `+ ربط ابن جديد`.

#### 🔹 [المسار 2.3] `POST /api/v1/guardians` — إنشاء ملف ولي أمر جديد:
* **تدفق التفاعل:** فتح اللوحة الجانبية المنبثقة (**Slide-over Drawer**) بعرض `500px` لإدخال الاسم الكامل، رقم الهاتف (مطلوب وفريد)، صلة القرابة، وكلمة المرور.
* **خطأ تكرار الهاتف (`409 Conflict`):** راية تنبيه حمراء بالدرور "رقم هاتف ولي الأمر مسجل مسبقاً".

#### 🔹 [المسار 3.2] `POST /api/v1/guardian-students` — ربط ولي أمر بطالب:
* **تدفق التفاعل:** عند الضغط على `+ ربط ابن جديد` يفتح نموذج منبثق يتيح البحث عن الطالب وتحديد حقل الوصي الرئيسي `is_primary`.
* **نجاح الربط (`201 Created`):** إغلاق النافذة وإظهار Toast أخضر "تم ربط الطالب بولي الأمر بنجاح" وتحديث قائمة الأبناء بالدرور.
