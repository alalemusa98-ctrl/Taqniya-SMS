### 1.2 التفاصيل والتصميم والتفاعل مع المسارات (Detailed UI & Route Action Flow):

#### 🔹 [المسار 1.1] `GET /api/v1/student-enrollments` — عرض وتصفية جدول التسكين:
* **شكل المكون بالواجهة (Listing Component):**
  - **جدول تسكين الشعب (Enrollment Data Table):** يستعرض الأعمدة:
    1. `#` (`id`).
    2. `كود الطالب` (شارة `student_code` مثل `STU-3001`).
    3. `اسم الطالب الرباعي` (`student_name`).
    4. `الصف والتسلسل` (`class_name` - `grade_level`).
    5. `الشعبة المدرسية` (شارة ملونة `section_name`).
    6. `رقم الجلوس` (شارة خضراء `seating_number`).
    7. `الحالة الأكاديمية` (شارة حالة `status`: مقيد `enrolled`, ناجح `passed`, دور ثانٍ `second_round`, راسب `failed`, متخرج `graduated`).
    8. `الإجراءات` (معاينة الأرشيف 👁️، أيقونة التعديل ✏️، وأيقونة الإلغاء 🗑️).
  - **شريط الفلترة والبحث العلوي (Filter Header):**
    - شريط بحث نصي باسم الطالب، الكود، أو رقم الجلوس.
    - قائمة منسدلة `Select Dropdown` لفلترة الصفوف الدراسية.
    - قائمة منسدلة لفلترة الشعب المدرسية.
    - قائمة منسدلة لفلترة الحالة الأكاديمية.
    - أزرار التحكم العلوية: زر أزرق `+ تسكين طالب` وزر أخضر `⚡ التوزيع الجماعي`.
  - **شريط الترقيم المالي (Pagination Bar):** أسفل الجدول يستعرض `meta.total`, `meta.page`, و `meta.per_page`.
* **حالات المعالجة المرئية (UI States):**
  - **Loading State:** عرض هيكل رمادي متأرجح (Skeleton Table Loader).
  - **Empty State:** رسالة توضيحية "لم يتم تسكين أي طلاب في هذه الشعبة بالعام النشط بعد".

#### 🔹 [المسار 1.2] `GET /api/v1/students/:student_id/enrollments` — عرض أرشيف تسكين طالب:
* **شكل المكون وتدفق التفاعل:** عند الضغط على 👁️ المعاينة أمام الطالب، يتم فتح اللوحة الجانبية المنبثقة (**Slide-over Drawer**) بعرض `500px` لعرض كارت معتم تفصيلي يستعرض كافة السجلات التاريخية لتسكين الطالب عبر الأعوام الدراسية السابقة والحالية.

#### 🔹 [المسار 1.3] `POST /api/v1/student-enrollments` — تسكين وتسجيل طالب فردي:
* **شكل المكون وتدفق التفاعل (Create Flow & Interaction):**
  - عند الضغط على زر `+ تسكين طالب` يتم فتح **لوحة جانبية منبثقة (Slide-over Drawer)** بعرض `500px` مع غطاء خلفي معتم (Backdrop Dim).
  - **حقول النموذج بالدرور (Form Controls):**
    1. `العام الدراسي` (اختيار العام النشط تلقائياً).
    2. `اختر الطالب` (قائمة منسدلة مع بحث ذكي بالاسم أو الكود `STU-XXXX`).
    3. `الصف والشعبة الدراسية` (قائمة منسدلة لاختيار `class_section_id`).
    4. `رقم الجلوس` (حقل نصي اختياري `seating_number`).
  - **أزرار التحكم:** زر `تأكيد تسكين الطالب` (باللون الأزرق) وزر `إلغاء`.
* **سلوك المعالجة والتنبيهات (Response Handlers):**
  - **نجاح التسكين (`201 Created`):** إغلاق الدرور تلقائياً، إظهار تنبيه نجاح أخضر "تم تسكين وتنسيق الطالب بالفصل والشعبة بنجاح"، وتحديث مصفوفة التسكين.
  - **خطأ التكرار السنوي (`409 Conflict`):** راية تنبيه حمراء بالدرور "الطالب مسكن مسبقاً في هذا العام الدراسي".

#### 🔹 [المسار 1.4] `PUT /api/v1/student-enrollments/:id` — تعديل التسكين ورقم الجلوس:
* عند الضغط على أيقونة التعديل ✏️، فتح **نفس اللوحة الجانبية المنبثقة (Slide-over Drawer)** تتيح نقل الطالب لشعبة أخرى في نفس الصف أو تعديل رقم الجلوس أو تحديث الحالة الأكاديمية.
* **نجاح التعديل (`200 OK`):** إغلاق الدرور وإظهار Toast أخضر "تم تحديث بيانات التسكين ورقم الجلوس بنجاح".

#### 🔹 [المسار 1.5] `POST /api/v1/student-enrollments/bulk-enroll` — التسكين الجماعي للطلاب:
* عند الضغط على زر `⚡ التوزيع الجماعي` يفتح نموذج منبثق لاختيار الشعبة وتحديد قائمة الطلاب غير المسكنين وتوزيعهم دفعة واحدة بحادث ذري.

#### 🔹 [المسار 1.6] `DELETE /api/v1/student-enrollments/:id` — إلغاء وتجريد تسكين طالب:
* عند الضغط على أيقونة الإلغاء 🗑️ يتم فتح **نافذة تأكيد مركزية (Confirmation Modal Alert)**.
* **حظر الإلغاء المرجعي (`403 Forbidden`):** إظهار تنبيه تحذيري: "لا يمكن إلغاء التسكين لارتباط الطالب بدرجات مرصودة بالسجل الأكاديمي (RESTRICT)".
