# 🧪 مصفوفة الاختبارات والتحقق — المرحلة 08 (Testing Specification)

> **الهدف:** توثيق مصفوفة الاختبارات الشاملة (Unit, Integration, Security, Invariant Integrity) للمرحلة 08 لضمان جودة الأكواد ومطابقتها التامة لـ [`routes.md`](./routes.md)، [`backend.md`](./backend.md)، و [`MD/database.md`](../../database.md).

---

## 1. استراتيجية الاختبارات العامة (Testing Strategy)

- **نمط الاختبار:** اختبارات تكاملية للـ API، اختبارات التحقق من قيود قاعدة البيانات (`uq_official_exam_schedule`)، واختبارات حوكمة الصلاحيات (RBAC).
- **التغطية المطلوبة:** 100% لكافة مسارات الـ API الـ 7، وقواعد التحقق، وحالات التعارض والمنع (409 Conflict).
- **البيئة المعتمدة:** بيئة اختبار معزولة (Test Database) يتم تصفيرها وإعادة ضبطها تلقائياً قبل كل جولة اختبار.

### 2.1 اختبارات جدول الامتحانات الرسمية (`official_exams`) — [الخطوة 1]

| معرف الاختبار (Test ID) | نوع الاختبار | السيناريو ووصف الحالة | المدخلات المتوقعة | النتيجة والرمز المتوقع |
| :--- | :--- | :--- | :--- | :--- |
| `TC-EXM-01` | **Integration** | استرجاع جدول الامتحانات بالهيكل الهرمي مع الفلترة والترقيم | `GET /api/v1/official-exams?class_id=3&academic_term_id=1&page=1` | `200 OK` مع الهيكل الهرمي للصفوف وأنواع الامتحانات والمواد و `meta`. |
| `TC-EXM-02` | **Integration** | البحث النصي باسم المادة أو التعليمات | `GET /api/v1/official-exams?search=رياضيات` | `200 OK` ومطابقة السجلات المطلوبة. |
| `TC-EXM-03` | **Integration** | استرجاع تفاصيل سجل امتحان رسمي محدد بالمعرف | `GET /api/v1/official-exams/1` | `200 OK` وتفاصيل الموعد والقاعة والملاحظات. |
| `TC-EXM-04` | **Integration** | استرجاع جدول امتحانات الصف الدراسي المعتمد بالسمستر | `GET /api/v1/classes/3/official-exams?exam_type=midterm` | `200 OK` وهيكل جدول امتحانات الصف بالكامل. |
| `TC-EXM-04B` | **Integration** | استرجاع جدول الامتحانات الرسمية لمواد معلم محدد | `GET /api/v1/teachers/3/official-exams` | `200 OK` ومصفوفة امتحانات المواد المسندة للمعلم. |
| `TC-EXM-05` | **Unit / Validation** | **جدولة امتحان رسمي بنجاح:** إضافة موعد امتحان جديد لصف ومادة | `year: 1, term: 1, class: 3, subject: 2, type: 'midterm', date: '2026-11-15'` | `201 Created` وحفظ السجل بجدول `official_exams`. |
| `TC-EXM-06` | **Conflict / Invariant** | **قيد تفرد جدولة المادة (uq_official_exam_schedule):** منع تكرار جدولة نفس المادة والنوع بالسمستر | محاولة جدولة امتحان نصفي لنفس المادة والصف بالسمستر مجدداً | `409 Conflict` (`uq_official_exam_schedule`). |
| `TC-EXM-07` | **Validation** | رفض مدخلات بدون تاريخ امتحان أو بمعرف مادة غير صالح | `exam_date: '', subject_id: 9999` | `422 Unprocessable Entity`. |
| `TC-EXM-08` | **Integration** | **تعديل موعد الامتحان بنجاح:** تحديث تاريخ الامتحان والتعليمات | `PUT /api/v1/official-exams/1` مع `exam_date: '2026-11-16'` | `200 OK` وتحديث السجل. |
| `TC-EXM-09` | **Soft Delete** | حذف وإلغاء امتحان رسمي من الجدول المعتمد | `DELETE /api/v1/official-exams/1` | `200 OK` وضبط `deleted_at` وتحديث السجل. |

### 2.2 اختبارات الأمان وحوكمة الصلاحيات (Security & RBAC Tests)

| معرف الاختبار (Test ID) | نوع الاختبار | السيناريو ووصف الحالة | المستخدم المنفذ | النتيجة والرمز المتوقع |
| :--- | :--- | :--- | :--- | :--- |
| `TC-AUTH-01` | **Auth** | محاولة الوصول لأي مسار بدون توكن مصادقة | زائر (Unauthenticated) | `401 Unauthorized`. |
| `TC-AUTH-02` | **Auth** | محاولة الوصول بتوكن تالف أو منتهي الصلاحية | توكن غير صالح | `401 Unauthorized`. |
| `TC-RBAC-01` | **RBAC** | محاولة المعلم أو الطالب أو ولي الأمر إضافة أو تعديل أو حذف امتحان | `role_type = 'teacher' / 'student' / 'parent'` | `403 Forbidden`. |
| `TC-RBAC-02` | **RBAC** | سماح لكافة المستخدمين المصادق عليهم باستعراض جداول الامتحانات | أي مستخدم مسجل | `200 OK`. |
| `TC-AUDIT-01` | **Audit** | التحقق من تتبع وتسجيل عمليات إضافة وتعديل وحذف الامتحانات في `audit_logs` | مدير النظام (`admin`) | تسجيل السجل الحركي متضمناً `old_values` و `new_values`. |
