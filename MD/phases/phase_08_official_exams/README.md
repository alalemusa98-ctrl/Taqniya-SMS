## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ومفصلة لخطوات وإجراءات جدولة ونشر ومتابعة الامتحانات الرسمية للنصف والنهائي والدور الثاني:

1. **الخطوة 1: إدارة جدول الامتحانات الرسمية (`official_exams`):** 6 مسارات.
   - عرض قائمة وتصفية جدول الامتحانات الرسمية (`GET /api/v1/official-exams`).
   - عرض تفاصيل امتحان رسمي محدد (`GET /api/v1/official-exams/:id`).
   - عرض جدول الامتحانات الرسمية الكامل لصف دراسي محدد (`GET /api/v1/classes/:class_id/official-exams`).
   - إضافة وجدولة امتحان رسمي جديد (`POST /api/v1/official-exams`).
   - تعديل موعد أو نوتس/تعليمات امتحان رسمي (`PUT /api/v1/official-exams/:id`).
   - إلغاء وحذف امتحان رسمي من الجدول (`DELETE /api/v1/official-exams/:id`).
