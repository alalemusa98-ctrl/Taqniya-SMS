# 🎨 مواصفات الواجهة الأمامية — المرحلة 10: النسخ الاحتياطي (Frontend Specs)

> **المواصفات الفنية للواجهات والتصميم بنظام تقنية للتصميم (Vue 3 + TailwindCSS + Spatial UI Tokens).**

---

## 1. الهيكل العام لصفحة إدارة النسخ الاحتياطي (`BackupManagementView.vue`)

### 📊 أ. بطاقات مؤشرات الأداء (KPI Cards):
1. **إجمالي النسخ الاحتياطية:** يعرض العدد الإجمالي للنسخ مع شارات تفصيلية للأنواع الثلاثة (كاملة / قاعدة بيانات / ملفات).
2. **المساحة التخزينية الإجمالية:** يوضح حجم النسخ الكلي في السيرفر.
3. **أحدث نسخة احتياطية:** يعرض تاريخ وتوقيت أحدث عملية نسخ منشأة.
4. **حالة محرك الاستعادة:** شارة نبضية خضراء تؤكد جاهزية محرك الاستعادة الذري.

### 🗂️ ب. شريط التبويبات الثلاثي (Type Filter Tabs):
شريط تبويبات تفاعلي يتيح التصفية السريعة:
- 📦 **الكل (All Backups)**: عرض جميع النسخ.
- 📦 **نسخة شاملة (Full Backups)**: تصفية النسخ الكاملة.
- 🗄️ **قاعدة البيانات (Database Only)**: تصفية نسخ الـ SQL فقط.
- 📁 **الملفات والمرفقات (Files Only)**: تصفية حزم المرفقات والملفات.

---

## 2. النوافذ المنبثقة التفاعلية (Modals Specifications)

### 1. نافذة إنشاء نسخة جديدة (`CreateBackupModal.vue`):
- **اختيار نوع النسخة (Type Selector Cards):**
  - بطاقة **نسخة شاملة كاملة (Full Backup)**: تشمل قاعدة البيانات + المرفقات والملفات.
  - بطاقة **قاعدة البيانات فقط (Database Only)**: تفريغ خفيف وفوري لـ MySQL (موصى بها للعمليات اليومية).
  - بطاقة **الملفات فقط (Files Only)**: أرشفة مجلد المرفقات والملفات المرفوعة.
- **حقل الملاحظة التوثيقية:** إدخال نص اختياري مع نماذج واقتراحات سريعة جاهزة للنقر.
- **زر التأكيد:** تشغيل مؤشر التحميل مع تعطيل النقرات المتكررة.

### 2. نافذة الاستعادة (`RestoreBackupModal.vue`):
- تنبيه تحذيري بارز يوضح العمليات التي سيتم استبدالها بناءً على نوع النسخة المستهدفة (بيانات أو ملفات أو كلاهما).
- اشتراط تأكيد المسؤول قبل بدء عملية الاستعادة.

### 3. نافذة الرفع والاستيراد (`UploadBackupModal.vue`):
- منطقة سحب وإفلات لملفات ZIP مع شريط تقدم وفحص تلقائي لنوع النسخة.

### 4. نافذة تأكيد الحذف (`DeleteModal`):
- نافذة حمراء لتأكيد الحذف النهائي للملف من السيرفر.
