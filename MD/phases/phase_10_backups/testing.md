# 🧪 مصفوفة الاختبارات المعيارية — المرحلة 10: النسخ الاحتياطي (Testing Matrix)

> **الهدف:** توثيق حالات الاختبار الشاملة للـ Backend والـ Frontend لضمان سلامة وأمان عمليات النسخ الاحتياطي والاستعادة.

---

## 📋 مصفوفة الاختبارات الآلية (Test Cases)

| رمز الاختبار | النوع | الوصف والسيناريو | النتيجة المتوقعة |
| :--- | :---: | :--- | :--- |
| `TC-BCK-01` | Integration | جلب قائمة النسخ عبر `GET /api/v1/backups` بصلاحية `admin`. | نجاح برمز `200 OK` واسترجاع إحصائيات ومصفوفة النسخ. |
| `TC-BCK-02` | Security | محاولة الوصول لقائمة النسخ بصلاحية `teacher` أو `student`. | رفض فوري برمز `403 Forbidden`. |
| `TC-BCK-03` | Integration | إنشاء نسخة احتياطية جديدة مع ملاحظة عبر `POST /api/v1/backups/create`. | نجاح برمز `201 Created` وتوليد ملف ZIP يحتوي على `database.sql` و `note.txt`. |
| `TC-BCK-04` | Unit | فحص سلامة استخراج وقراءة الملاحظة وحجم الملف من داخل أرشيف ZIP. | قراءة نص الملاحظة السليم وحجم البايتات دون فك ضغط كامل الأرشيف. |
| `TC-BCK-05` | Integration | تنزيل ملف النسخة عبر `GET /api/v1/backups/download/:filename`. | استرجاع الدفق الثنائي بصيغة `application/zip` وترويسات التنزيل. |
| `TC-BCK-06` | Integration | حذف نسخة احتياطية عبر `DELETE /api/v1/backups/:filename`. | نجاح الحذف برمز `200 OK` وإزالة الملف نهائياً من مسار التخزين. |
| `TC-BCK-07` | Validation | محاولة حذف أو تنزيل ملف غير موجود بالسيرفر. | استجابة خطأ برمز `404 Not Found`. |
| `TC-BCK-08` | Unit | اختبار تجزئة استعلامات SQL مع تعطيل وإعادة تفعيل `FOREIGN_KEY_CHECKS`. | استعادة كاملة دون أخطاء قيود المفاتيح الأجنبية. |
