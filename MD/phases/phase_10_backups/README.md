# 🛡️ المرحلة 10: إدارة النسخ الاحتياطي واستعادة قاعدة البيانات (Backups & Disaster Recovery)

> **الملف التعريفي الرئيسي للمرحلة العاشرة وفق معايير إطار عمل تقنية (Taqniya Framework v1.0).**

---

## 📌 1. نبذة عن المرحلة (Phase Overview)
- **اسم المرحلة:** إدارة النسخ الاحتياطي واستعادة البيانات (`phase_10_backups`).
- **الهدف العام:** تزويد الإدارة العليا للنظام بمحرك متكامل وآمن للنسخ الاحتياطي الشامل لقاعدة البيانات (MySQL)، وضغطها بتنسيق قياسي (`.zip`) يتضمن تفريغ الـ SQL والملاحظات الوصفية، مع إتاحة الاستعادة الفورية، التنزيل، الرفع من الجهاز الخارجي، والحذف، لضمان استمرارية العمل والتعافي من الكوارث (Disaster Recovery).
- **الجهة المستفيدة والأدوار:** الإدارة العليا فقط (`role_type = 'admin'`).

## 🎯 2. نطاق المرحلة والمسارات المعمارية (Scope & Architecture)

### 📋 مصفوفة المسارات الستة (Master Endpoints):
| # | المسار | HTTP Method | الصلاحية | الغرض الوظيفي |
| :-: | :--- | :---: | :---: | :--- |
| **1** | `/api/v1/backups` | `GET` | `admin` | استعراض قائمة النسخ الاحتياطية وإحصائيات الحجم والتاريخ والملاحظات. |
| **2** | `/api/v1/backups/create` | `POST` | `admin` | إنشاء وتوليد نسخة احتياطية فورية ومضغوطة مع ملاحظة اختيارية. |
| **3** | `/api/v1/backups/upload` | `POST` | `admin` | رفع واستيراد ملف نسخة احتياطية `.zip` من جهاز المستخدم. |
| **4** | `/api/v1/backups/restore/:filename` | `POST` | `admin` | استعادة قاعدة البيانات من ملف نسخة احتياطية محدد مع حوكمة القيود. |
| **5** | `/api/v1/backups/download/:filename` | `GET` | `admin` | تنزيل ملف النسخة الاحتياطية المضغوط إلى جهاز المستخدم. |
| **6** | `/api/v1/backups/:filename` | `DELETE` | `admin` | حذف ملف النسخة الاحتياطية نهائياً من وحدة التخزين بالسيرفر. |

## 🔒 4. محددات الأمان والحوكمة (Security & Invariants)
1. **صلاحية حصرية للإدارة العليا (Admin-Only RBAC):** يُمنع المعلمون والطلاب وأولياء الأمور منعاً باتاً من الوصول لأي مسار نسخ احتياطي برفض فوري برمز `403 Forbidden`.
2. **عزل القيود المفتاحية أثناء الاستعادة:** تنفيذ استعلامات الاستعادة بداخل سياق محمي يبدأ بـ `SET FOREIGN_KEY_CHECKS=0;` وينتهي بإعادة التفعيل `SET FOREIGN_KEY_CHECKS=1;`.
3. **تفريغ دفعي للبيانات (Chunked Export):** تصدير الجداول الكبيرة عبر دفعات متتالية (500 سجل) لمنع استهلاك الذاكرة العشوائية للسيرفر.
4. **تسجيل وتوثيق العمليات (Audit Logging):** توثيق كل عملية إنشاء، استعادة، رفع، أو حذف في سجل العمليات الإدارية لضمان المساءلة والحماية.
