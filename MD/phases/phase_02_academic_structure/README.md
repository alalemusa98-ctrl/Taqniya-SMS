# 📦 Phase 02: الهيكل الأكاديمي والمناهج (Academic Structure & Curriculum)

> **الملف التعريفي والتوجيهي الرئيسي لمرحلة بناء الهيكل الأكاديمي والمناهج الدراسية بنمط واجهات برمجة التطبيقات (API-First).**

---

## 📌 1. بطاقة تعريف المرحلة (Phase Metadata)

- **اسم المرحلة البرمجي:** `phase_02_academic_structure`
- **عنوان المرحلة:** الهيكل الأكاديمي والمناهج (Academic Structure & Curriculum).
- **نمط الاتصال المعماري:** `API-First` (`mode: api_first` في `MD/stack.yaml`).
- **حالة المرحلة:** 🟢 المرحلة الأساسية للبنية الأكاديمية (Foundational Academic Phase).
- **الهدف العام:** بناء وإدارة الهيكل التنظيمي الأكاديمي للمدرسة بالكامل وفق التسلسل الأكاديمي الواقعي:
  1. إدارة التقويم الدراسي والسنوات الدراسية وتحديد السنة النشطة.
  2. إدارة الفترات/الفصول الدراسية وتحديد الفترة النشطة التابعة للسنة.
  3. إدارة المراحل التعليمية (تمهيدي، ابتدائي، إعدادي، ثانوي).
  4. إدارة الصفوف الدراسية وتحديد تبعية الصفوف للمراحل (مثل: الصفوف 1-6 ابتدائي، 7-9 إعدادي، 10-12 ثانوي).
  5. إدارة بنك الشُعب العامة (أ، ب، ج، د).
  6. إدارة بنك المواد الدراسية العامة (رياضيات، علوم، لغة عربية...).
  7. ربط وتسكين الشُعب بالصفوف (مثل: فتح الشعبة أ والشعبة ب للصف الخامس -> خامس/أ، خامس/ب).
  8. ربط وإسناد المواد للصفوف وتحديد الدرجة العظمى ودرجة النجاح المخصصة لكل فترة دراسية باستقلالية.

## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work & Sequential Lifecycle)

### 🟢 ما تشمله المرحلة (In-Scope):
توفير واجهات RESTful API متكاملة ومؤمنة، وشاشات تفاعلية (`dir="rtl"`) للخطوات الثمانية المترتبة تسلسلياً:

1. **إدارة السنوات الدراسية (`academic_years`):**
   - إنشاء، تعديل، حذف، وعرض السنوات الدراسية (مثال: `2025/2026`, `2026/2027`).
   - تحديد السنة النشطة حالياً (`is_current = 1`) مع ضمان سنة نشطة واحدة فقط ذرياً.
2. **إدارة الفترات/الفصول الدراسية (`academic_terms`):**
   - إنشاء، تعديل، حذف، وعرض الفترات الدراسية (مثال: `الفترة الأولى`, `الفترة الثانية`, `الفترة الثالثة`).
   - تفعيل الفترة النشطة حالياً ضمن السنة النشطة.
3. **إدارة المراحل التعليمية (`academic_stages`):**
   - إنشاء، تعديل، حذف، وعرض المراحل (مثال: `مرحلة التمهيدي`, `المرحلة الابتدائية`, `المرحلة الإعدادية`, `المرحلة الثانوية`).
4. **إدارة الصفوف الدراسية وتحديد تبعيتها للمراحل (`classes`):**
   - إنشاء، تعديل، حذف، وعرض الصفوف وتحديد تبعيتها للمرحلة (مثال: الصف الأول، الثاني، الثالث، الرابع، الخامس، السادس يتبعون `المرحلة الابتدائية`؛ الصف السابع، الثامن، التاسع يتبعون `المرحلة الإعدادية`؛ الصف العاشر، الحادي عشر، الثاني عشر يتبعون `المرحلة الثانوية`).
5. **إدارة بنك الشُعب العامة (`sections`):**
   - إنشاء، تعديل، حذف، وعرض مسميات الشُعب العامة في المدرسة (مثال: `الشعبة أ`, `الشعبة ب`, `الشعبة ج`).
6. **إدارة بنك المواد الدراسية العامة (`subjects`):**
   - إنشاء، تعديل، حذف، وعرض بنك المواد الدراسية ورموزها (مثال: `الرياضيات` - `MATH`, `العلوم` - `SCI`, `اللغة العربية` - `ARAB`).
7. **إدارة ربط الشُعب بالصفوف (`class_sections`):**
   - تخصيص وفتح الشُعب المتاحة لكل صف دراسي (مثال: الصف الخامس تفتح له الشعبة أ والشعبة ب لتشكيل `خامس/أ` و `خامس/ب`).
8. **إدارة مناهج الصفوف والدرجات لكل فترة دراسية (`class_subjects`):**
   - إسناد المواد للصفوف الدراسية وتحديد الدرجة العظمى (`max_score`) ودرجة النجاح (`pass_score`) المخصصة لكل فترة دراسية على حدة.
   - *مثال واقعي:* إذا كان الصف الخامس يحتوي على "الفترة الأولى" و"الفترة الثانية"، فيتم تحديد درجة مادة الرياضيات للفترة الأولى (مثال: العظمى 100 والنجاح 50)، وللفترة الثانية (مثال: العظمى 100 والنجاح 50) بشكل مستقل ومفصل لكل فصل دراسي.
