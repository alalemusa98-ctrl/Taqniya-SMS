## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ومفصلة لخطوات وإجراءات إنشاء ونشر ومتابعة الواجبات المدرسية على مستوى الشعبة والصف الدراسي كاملة:

1. **الخطوة 1: إدارة الواجبات المدرسية والتكاليف المنزلية (`assignments`):** 8 مسارات.
   - عرض قائمة وتصفية الواجبات المدرسية بالصف والشعبة والمادة (`GET /api/v1/assignments`).
   - عرض تفاصيل واجب مدرسي محدد (`GET /api/v1/assignments/:id`).
   - عرض واجبات شعبة محددة في السمستر الحالي (`GET /api/v1/sections/:section_id/assignments`).
   - عرض واجبات صف دراسي محدد بغض النظر عن الشعبة (`GET /api/v1/classes/:class_id/assignments`).
   - عرض الواجبات المنشأة بواسطة معلم محدد (`GET /api/v1/teachers/:teacher_id/assignments`).
   - إنشاء ونشر واجب مدرسي جديد (`POST /api/v1/assignments`).
   - تعديل بيانات ومرفقات وموعد واجب مدرسي (`PUT /api/v1/assignments/:id`).
   - حذف واجب مدرسي من المنظومة (`DELETE /api/v1/assignments/:id`).
