## 🎯 2. نطاق العمل والتسلسل التنفيذي (Scope of Work)

تغطية شاملة ومفصلة للخطوات الثلاث:

1. **الخطوة 7: إدارة تواريخ وتخطيط فترات الصفوف (`class_academic_terms`):** 4 مسارات.
   - عرض فترات وتواريخ صف بالعام، تخصيص وتخطيط فترة وتواريخ لصف (يلائم 3 فترات للشهادات 9 و 12)، تفعيل الفترة النشطة للصف، وإغلاق/فتح درجات الفترة للصف.
2. **الخطوة 8: إدارة ربط وتسكين الشُعب بالصفوف (`class_sections`):** 3 مسارات.
   - عرض شعب صف مفتوحة، تسكين/ربط شعبة بصف (`class_id`, `section_id`)، وفك ربط شعبة من صف.
3. **الخطوة 9: إدارة مناهج الصفوف والدرجات لكل فترة (`class_subjects`):** 4 مسارات.
   - عرض منهج الصف بالفترة، إسناد مادة وتحديد درجات الفترة (`class_id`, `subject_id`, `class_academic_term_id`, `passing_score`, `max_score`), تعديل درجات مادة بالفترة، وإزالة مادة من منهج فترة.
