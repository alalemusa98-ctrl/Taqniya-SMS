# 📖 دليل توثيق مشروع نظام إدارة المدارس (Taqniya-SMS MD)

> **الملف التعريفي الرئيسي لنظام توثيق مشروع إدارة المدارس المُوجّه للذكاء الاصطناعي (AI-Driven Documentation) وفق معايير إطار عمل تقنية (Taqniya Framework).**

---

## 📌 1. نبذة عن المشروع (Project Overview)
- **اسم المشروع:** نظام إدارة المدارس الذكي — Taqniya School Management System (`Taqniya-SMS`).
- **الهدف العام:** بناء منصة برمجية متكاملة وسحابية لإدارة كافة العمليات الأكاديمية، الإدارية، والمالية في المؤسسات التعليمية (المدارس والمجمعات التعليمية)، وتسهيل التواصل الفوري بين الإدارة، المعلمين، أولياء الأمور، والطلاب.
- **طبيعة النظام:** منصة ويب حديثة منفصلة بالكامل (Decoupled SPA) تعمل بنمط **`API-First`** مع واجهة أمامية تفاعلية ولوحات تحكم مخصصة لكل دور.
- **الستاك التقني المعتمد:**
  * **Backend:** Express.js (Node.js) — Clean Architecture (Controllers / Services / Repositories).
  * **Frontend:** Vue.js 3 (Composition API) + Pinia + Tailwind CSS (Spatial UI).
  * **Database:** MySQL 8.0 (InnoDB / UTF8mb4) — SSoT via `MD/database.md`.
  * **Authentication:** Stateless JWT Tokens + Role-Based Access Control (RBAC).
- **الحالة الحالية:** 🏗️ مرحلة التأسيس واستيعاب قواعد العمل وتصميم قاعدة البيانات.

## 🎯 2. نطاق المشروع (Project Scope)

### 🟢 ما يتضمنه المشروع (In Scope):
1. **المصادقة والصلاحيات (Auth & RBAC):** إدارة المستخدمين والأدوار المتعددة (مدير، مسؤول نظام، معلم، طالب، ولي أمر، محاسب).
2. **الهيكل الأكاديمي (Academic Structure):** إدارة الأعوام الدراسية، الفصول، المراحل التعليمية، الشعب، والمناهج/المواد.
3. **إدارة الكادر التعليمي (Teachers & Staff):** ملفات المعلمين، تعيين المواد والفصول، والجداول التدريسية.
4. **شؤون الطلاب والتسجيل (Student Admissions & Enrollment):** تسجيل الطلاب الجدد، ملفاتهم، ربط أولياء الأمور، وتوزيع الشعب.
5. **إدارة الجداول والحصص (Timetables):** إنشاء وتوزيع الحصص الأسبوعية تلقائياً ويدوياً ومنع التعارض.
6. **سجل الحضور والغياب (Attendance):** تسجيل الحضور اليومي والحصص، تتبع الأعذار، وإشعارات الغياب الفورية.
7. **الاختبارات والتقييم والشهادات (Exams & Grading):** بنية الدرجات والتقييمات المستمرة، إدخال الدرجات، حساب المعدلات، واستخراج بطاقات الدرجات والشهادات.
8. **المالية والرسوم المدرسية (Student Fees & Accounting):** هياكل الرسوم، الأقساط، الفواتير، سندات القبض والدفع، وتقارير التحصيل.
9. **بوابات الخدمة الذاتية (Portals):** لوحة تحكم ولي الأمر لمتابعة أبنائه، ولوحة الطالب لمتابعة الواجبات والدرجات.
10. **التقارير والإحصائيات والتحليلات (Reports & Dashboard KPIs):** تقارير تفصيلية ورسوم بيانية وإمكانية التصدير (PDF/Excel).

### 🔴 ما لا يتضمنه المشروع في المرحلة الأولى (Out of Scope):
- الفصول الافتراضية المباشرة عبر الفيديو (Live Video Conferencing).
- نظام إدارة حافلات النقل المدرسي عبر GPS (مؤجل لمرحلة لاحقة).
- متجر بيع الزي المدرسي والكتب الإلكتروني المستقل.

## 💡 5. آلية وتكامل دورة حياة المشروع مع الذكاء الاصطناعي

تتبع كافة عمليات التطوير دورة حياة محكومة ومغلقة:
1. **التهيئة والتحقق:** مراجعة التوافق بين `stack.yaml` و `frontend_capabilities.yaml` و `execution_engine.yaml`.
2. **استيعاب المجال (Domain Analysis):** تحليل `business_rules.md` و `data.md` لضمان صحة المنطق التعليمي والإداري.
3. **قاعدة البيانات كمرجع وحيد (Database SSoT Gate):** إنشاء واعتماد `MD/database.md` بجميع الجداول والعلاقات والقيود قبل كتابة أي سطر كود برمجي.
4. **تنفيذ المراحل (Phase Lifecycles):** لكل مرحلة ملفاتها المستقلة (`README.md`, `routes.md`, `backend.md`, `frontend.md`, `data.md`) واجتياز بوابات المراجعة الثمانية.
