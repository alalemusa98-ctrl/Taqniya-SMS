# 📖 دليل توثيق مشروع نظام إدارة المدارس (Taqniya-SMS MD)

> **الملف التعريفي الرئيسي لنظام توثيق مشروع إدارة المدارس المُوجّه للذكاء الاصطناعي (AI-Driven Documentation) وفق معايير إطار عمل تقنية (Taqniya Framework).**

---

## 📌 1. نبذة عن المشروع (Project Overview)
- **اسم المشروع:** نظام إدارة المدارس الذكي — Taqniya School Management System (`Taqniya-SMS`).
- **الهدف العام:** بناء منصة برمجية موحدة لإدارة الهيكل الأكاديمي، إسناد التدريس، الجداول الدراسية، الواجبات، التطبيقات، والامتحانات، مع توفير تجربة قراءة تفاعلية للطالب وولي الأمر، وتجربة تحكم منضبطة للمعلم والإدارة.
- **طبيعة النظام:** منصة ويب حديثة منفصلة بالكامل (Decoupled SPA) تعمل بنمط **`API-First`** مع واجهة موحدة تدعم الهوية المؤسسية (`user_code`).
- **الستاك التقني المعتمد:**
  * **Backend:** Express.js (Node.js) — Clean Architecture (Controllers / Services / Repositories).
  * **Frontend:** Vue.js 3 (Composition API) + Pinia + Tailwind CSS (Spatial UI).
  * **Database:** MySQL 8.0 (InnoDB / UTF8mb4) — SSoT via `MD/database.md`.
  * **Authentication:** Stateless JWT Tokens + Standardized User Codes (`ADM-`, `TCH-`, `STU-`, `PAR-`).
- **الحالة الحالية:** 🏗️ مرحلة التأسيس واستيعاب قواعد العمل وتصميم قاعدة البيانات.

## 🎯 2. نطاق المشروع (Project Scope)

### 🟢 ما يتضمنه المشروع (In Scope):
1. **نظام الهوية والمصادقة الموحد (Unified Identity & Auth):** الدخول برمز المستخدم الموحد (`user_code`) + كلمة المرور لكافة الأدوار دون قوائم اختيار للأدوار.
2. **الهيكل الأكاديمي ثلاثي المستويات (Academic Hierarchy):** إدارة الأعوام، المراحل، الصفوف، الشعب، والمواد.
3. **مرونة إسناد التدريس (Teaching Assignments):** ربط (الشعبة + المادة + المعلم) مع إتاحة تعدد الفصول والمواد للمعلم.
4. **شؤون الطلاب وأولياء الأمور (Students & Guardians):** تسكين الطلاب، أرقام الجلوس، وعلاقات أولياء الأمور (سياق الابن).
5. **الجداول الدراسية والحصص (Timetables & Slots):** توزيع الحصص الأسبوعية (السبت - الخميس) وضبط أوقات الحصص.
6. **الواجبات والتطبيقات (Homework & Quizzes):** إدارة المعلمين للواجبات والتطبيقات ورصد درجاتها بوقت مفتوح، مع إمكانية مساندة الإدارة.
7. **جدول الامتحانات الرسمية (Official Midterm & Final Exams):** إنشاء ونشر جدول الامتحانات مركزياً من الإدارة.
8. **بوابات العرض التفاعلية (Unified Portals & Child Context):** 
   * واجهة موحدة تتعامل مع الموارد الأكاديمية الستة في الـ API.
   * واجهة المعلم المتطابقة بصرياً مع واجهة الطالب مع تزويدها بأزرار العمليات (إضافة/تعديل/حذف).
   * واجهة ولي الأمر للدخول في سياق الابن (Child Context) والتنقل بين الأبناء.
9. **محرك الترحيل الأكاديمي الذكي ونهاية العام (Year-End Promotion & Balanced Distribution):** فرز الناجحين والدور الثاني والراسبين وتوزيع الطلاب بالتساوي على الشعب بنقرة زر.

## 💡 5. آلية وتكامل دورة حياة المشروع مع الذكاء الاصطناعي

تتبع كافة عمليات التطوير دورة حياة محكومة ومغلقة:
1. **التهيئة والتحقق:** مراجعة التوافق بين `stack.yaml` و `frontend_capabilities.yaml` و `execution_engine.yaml`.
2. **استيعاب المجال (Domain Analysis):** تحليل `business_rules.md` و `data.md` لضمان صحة المنطق التعليمي والإداري.
3. **قاعدة البيانات كمرجع وحيد (Database SSoT Gate):** إنشاء واعتماد `MD/database.md` بجميع الجداول والعلاقات والقيود قبل كتابة أي سطر كود برمجي.
4. **تنفيذ المراحل (Phase Lifecycles):** لكل مرحلة ملفاتها المستقلة (`README.md`, `routes.md`, `backend.md`, `frontend.md`, `data.md`) واجتياز بوابات المراجعة الثمانية.
